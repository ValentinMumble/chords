# Chords

A simple guitar chord visualizer — a single HTML file, no dependencies, no build step.

## Features

- 28 common chords: open majors and minors, barre shapes, dominant/minor/major 7ths, sus and add chords
- Classic chord-chart fretboard diagrams with finger numbers, open/muted string markers, and barre indicators
- Note names under each string
- Audio playback via the Web Audio API: strum or play strings one by one to check your fingering by ear
- Keyboard navigation: `←` / `→` to change chord, `space` to strum, `a` for one-by-one
- Light and dark mode (follows system preference)

## Usage

Open `index.html` in any browser. That's it.

```sh
open index.html
```
